# Study v3 · 研究框架、双语原文与术语点读

## 不变的边界

原文PDF、book.json的英文文本与段落ID保持不变。公式显示、中文和术语都是单独的显示层；不能改写作者结论来配合教学解释。旧s编号、lesson-block编号和原文段落锚点必须保留。私人导入、便签和ND许可译文不得进入公开仓库。

## 内容组织

`frameworks.json`覆盖21个文献条目。每篇先说明科学问题、研究位置、输入—步骤—输出和结论边界，再将原有精读细节移入对应步骤的展开区。每一个旧section索引必须恰好出现一次。`study-map`为全局入口。`glossary.json`中的解释为带来源的教学释义，不冒充作者逐字定义。点击就地显示，外部点击或Escape关闭；不得破坏原生选字。

## 中文对照

公开译文只用于明确允许改编的来源。每份译文绑定原件SHA256，每段绑定标准化英文文本SHA256。`refine_translations.py`逐句、逐条目推理，避免整列PDF文字输入后漏掉后半段；保留每句输出的记录，不截断输入。默认是机器初译；数字自动检查只能提示问题，不能视为人工核对。

`curated-translations.json`记录已经对照过的段落，`apply_study_review.py`在源文件及原段匹配后应用，并单独标记reviewed。不得将其余初译改标为已核译。ND条款来源的中文仅由My-Evolution私有工作流生成私人导入包，禁止镜像到Evolution或Paper。

## 公式

`prepare_study_layout.py`沿原始文本块的连续顺序和严格栏位恢复公式完整区域，禁止从另一栏或相邻公式拼接片段；原始提取字串保留于折叠核对区。仅明确核验的表达式才额外生成MathML，仍保留原式裁图。单独检查梁2022的17个公式，式9—12的MathML需与原件一致。不要从乱码推测新的公式。

## 构建与验收

普通构建保持无网络、stdlib：`python scripts/build.py`。预处理原件需PyMuPDF，译文生成需固定CPU翻译工具；这些不是浏览器依赖。网站不得依赖外部CDN或新增字体文件。

发布前运行三个独立浏览器套件：`scripts/test_browser.py`、`scripts/test_reader.py`、`scripts/test_study.py`。必须覆盖框架旧链接、中文开关持久化、术语弹窗关闭、跨术语选字标注、连续/翻页、私人译文导入、离线新文章、公式核对图与手机宽度。原件更新后重新生成匹配的公式与译文；不匹配的旧译文不可继续冒充当前原文对照。

My-Evolution同步只增加审查过的文件白名单，绝不直接编辑Evolution镜像。
