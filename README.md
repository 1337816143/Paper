# Paper Lab · 农业系统论文带读

围绕 farming-systems analysis、multi-objective design 与 spatial decision support 的离线优先学习站。

## 内容边界

仅发布论文书目信息、原创中文带读、方法讲解、明确标注的教学示例与学习路线。不上传私人邮件、申请材料、签名、联系方式、录音、未授权论文全文或原始农户数据。每页区分原文支持、教学解释、研究迁移与待核实事项。

## 使用

站点提供逐篇阅读、方法索引、阅读位置恢复、跨页返回、离线缓存、单文件 HTML / ZIP 下载，以及本机笔记与进度导入导出。外部论文链接仍需网络；浏览器可能清理缓存，应同时导出备份。

## 维护与发布

Paper 是论文学习内容的专业上游。My-Evolution 是个人进化网站唯一维护源，Evolution 是其发布镜像，不直接修改。内容变更通过 GitHub Actions 验证、生成与发布；ChatGPT 对话本身没有可用的自动完成事件，不能宣称网站可自行读取未提交的对话。

详细维护规范见 AGENTS.md。构建与离线包不依赖第三方 CDN。
