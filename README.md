# Paper Lab · 博士研究工作区

围绕 farming-systems analysis、multi-objective design 与 spatial decision support 的离线优先研究文献工作区。

## 版本与数据状态

程序版本由 `resources/application-release.json` 维护，当前为 **5.5.3**。页头显示易读版本；`release.json` 另保留准确源码提交和内容校验值。发布结果以标准 Pages 工作流与实际网址为准。

自动更新默认开启，但会等待所有同站标签页进入安全状态。输入、选字、弹窗、导入、本机翻译或当前页面内存中的 GitHub 同步会话存在时，不强制刷新。新版本启用后，曾完整缓存的设备自动补齐新增离线资源。版本更新不等于私人数据已获云端确认。

## 内容边界

发布论文书目信息、原创中文带读、方法讲解、明确标注的教学示例，以及许可明确的原文技术转换。私人邮件、申请材料、签名、联系方式、录音、未授权全文或原始农户数据不得进入公开仓库。每页区分原文支持、教学解释、研究迁移与待核实事项。

## 研究导航

六个主入口：研究总览、论文工作区、概念与方法、模型与软件、综合与创新、我的工作。22篇主文献的核读范围、附录、作者数据、代码和结果复现单独列出。既有问答以开放解说呈现；合成算例与可运行脚本直接可读，不设置答题、分数或解锁条件。旧版笔记、阅读位置和标记保留在原存储结构中。

## 使用

站点支持逐篇阅读、方法索引、原位置返回、离线缓存、逐段本机翻译、术语点读、划线与非模态便签、可编辑标签、DOI／题名检索、个人文件导入和备份。已归档原文可缓存；未取得或仅私有保存的资源不冒充公开全文。

私人数据在设备上优先保存，通过显式授权的私有 GitHub 分支合并与备份。授权只在当前页面内存中。**免填令牌的长期登录仍待安全服务端接入**，不能通过公开网页嵌入共享凭据实现。没有云端确认时，离线修改仍需保留本机；应另外保留完整备份。

## 维护与发布

Paper 是论文学习内容的专业上游。My-Evolution 是个人进化网站唯一维护源，Evolution 是其发布镜像，不直接修改。内容变更通过 GitHub Actions 验证、生成与发布；ChatGPT 对话本身没有可用的自动完成事件，不能宣称网站可自行读取未提交的对话。

详细维护规范见 AGENTS.md。构建与离线包不依赖第三方 CDN。常规设置、测试、发布与镜像同步由维护者完成；仅真正需要身份或外部服务授权的步骤交由用户确认。
