# 教学练习，不是论文原始复现

所有数值均为自编示例，不能用于农业建议、论文结果或真实海南农场结论。

```bash
python pareto_lab.py --test
python pareto_lab.py
python sequence_lab.py
Rscript multivariate_lab.R
```

Python脚本仅用标准库；R脚本仅用基础函数。首次安装Python/R后可离线运行。单元测试检查支配关系、重复点、层级排序、全部目标子集的效率分数、理想点距离与常数列处理。

第一课验收：能手算A/B/C之间的支配，说明重复点E为什么仍可保留，说明改变劳动目标如何影响方案F。
第二课验收：能证明[1,1,1]在全部两目标组合下非支配，而[0,2,2]在后两目标中被支配。
第三课验收：把每期劳动上限改成8或10，解释可行域变化。模型没有真实生长过程、价格反馈或风险。

完整结果复现还需作者数据、清洗规则、参数、补充材料和版本信息。详细分级见网站“核验与勘误”。
